Quote Builder

Dragon Electronics quotations from model numbers, in Yousouf's DP_ISL_100 format.

1 · Add the button to Chrome (once)

  1. Show the bookmarks bar: press Ctrl + Shift + B.
  2. Drag this red button onto the bookmarks bar:
    Quote Builder
    Dragging does not open it. If dragging does not work: right-click the bookmarks bar → Add page…, name it Quote Builder and paste the text below as the URL.

2 · First use: load your template (once)

  1. Open www.dragonelectronics.mu.
  2. Click Quote Builder on the bookmarks bar. A panel opens on the right.
  3. At the bottom of the panel, under Quotation template, choose template.xlsx from your computer.

The template, with the letterhead and signature, stays inside Chrome on your computer. It is never put on this website.

3 · Make a quotation

  1. On any dragonelectronics.mu page, click Quote Builder.
  2. Fill in the customer, the models (one per line, e.g. GC-X31FFCRB x2) and the terms.
  3. Click Generate quotation. The Excel file downloads by itself.
  4. For a PDF: open the file in Excel → File → Save As → PDF.

Good to know

Quote numbersDP | customer initials | running number. The last number used is remembered in Chrome and can be corrected in the panel.
PricesNormal retail price incl. VAT, or the promo price when you choose it. Promo prices are always listed after generating.
Model not foundThe panel says so and builds the quote with the others. Usually the product was removed from the website, or the code has a typo.
Other computerAdd the button and load the template on that computer too. The quote counter and history are separate per computer.
If it stops workingThe website layout probably changed. Products will show ✗ with a reason; the code then needs a small update.
